# training-checkpoint-time-travel-validator
验证训练检查点时间旅行、血缘和不可变恢复点

## 概述

`checkpoint_validator.py` 实现检查点时间旅行验证器（兼容 Python 3.8.2）。
给定 checkpoint DAG（父版本、参数/优化器分片清单、评估引用、导出指针）、
对象存储元数据（摘要、归档状态）和删除记录，判断任意历史版本是否仍可
完整恢复，并输出可恢复时间点、缺失对象、共享引用和安全清理范围。

**验证器只读取元数据，不加载模型权重。** 它仅检查清单、对象摘要、
删除记录与归档标记，适合在大规模训练集群上离线运行。

## 判定规则

满足以下全部条件的版本才可恢复：

- 所有祖先版本都存在于 DAG 中（父版本缺失则不可恢复）；
- 清单引用的每个参数/优化器/评估/导出对象都存在、未被有效删除，
  且摘要与清单一致；
- 每个优化器分片的 `param_version` 与本版本一致。

删除记录按发生时间 `at` 评估：若删除时仍有未退役版本引用该对象，
删除被拒绝（共享分片保护）——已被新版本引用的公共分片不能因旧时间点
退役而删除。删除之后才创建的版本（例如清单回滚）引用已删分片时，
视为对象缺失。

## 输出

`validate(snapshot)` 返回报告：

- `recoverable` / `unrecoverable`：可恢复时间点与不可恢复原因；
- `missing_objects`：每个版本缺失的对象；
- `shared_references` / `protected_deletions`：共享引用与被拒绝的删除；
- `safe_cleanup`：仅被退役版本引用或无人引用、可安全清理的对象；
- `views`：每个可恢复版本的 `RecoveryView`。

`RecoveryView` 是不可变快照（`MappingProxyType` / `frozenset` / 元组），
基于深拷贝构建，后续清理或修改输入不会悄悄改变已生成的恢复视图。

## 运行测试

```bash
python -m unittest
```

测试覆盖线性历史、分叉、共享分片、旧版本删除、清单回滚和视图不可变性。
